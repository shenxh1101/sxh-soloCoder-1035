# 电商运营桌面客户端

一款供多店铺运营人员集中整理商品和活动的桌面客户端应用。

## 功能模块

### 1. 商品库
- 商品列表展示，支持图片预览
- 多维度筛选：店铺、状态、分类、异常标记
- 支持 Excel/CSV 文件导入商品数据
- 商品信息编辑（标题、卖点、价格、库存等）
- 异常商品标记与管理
- 数据导出功能

### 2. 批量编辑
- 四步式批量操作流程
- 支持批量修改商品标题（替换/加前缀/加后缀）
- 支持批量修改卖点
- 支持批量调整价格（固定价/加价/减价/折扣）
- 支持批量调整库存
- 支持批量上下架操作
- 支持批量标记/解除异常

### 3. 活动日历
- 日历视图与列表视图双模式
- 活动信息管理：报名时间、活动时间、优惠规则
- 库存预留与负责人分配
- 活动状态追踪（草稿/待审核/已通过/已拒绝/进行中/已结束）
- 关联商品管理
- 日期维度活动查询

### 4. 素材管理
- 主图、详情图、短文案、长文案分类管理
- 素材审核流程（待审核/已通过/已拒绝）
- 图片预览与文案展示
- 素材与商品关联
- 按店铺、类型、审核状态筛选

### 5. 任务记录
- 任务全生命周期追踪（待处理/处理中/已完成/已失败）
- 优先级管理（高/中/低）
- 失败原因记录与任务重试
- 待复核任务管理
- 每日运营清单自动生成
- 任务进度可视化

## 技术栈

- **框架**: Electron + Vue 3 + TypeScript
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **日期处理**: Day.js
- **Excel处理**: SheetJS (xlsx)
- **CSV处理**: Papa Parse
- **数据持久化**: LocalStorage

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 仅构建前端

```bash
npm run build:only
```

- 30个商品演示数据
- 15个活动演示数据
